A schema-driven generic form built on react-hook-form and Zod.

`GenericForm` takes a Zod schema, derives `initialValues` and validation from
it, and shares the form instance through `FormProvider` so any child can query
context with `useFormContext()`. Field components like `TextField` read the
context and render the state without wiring a `Controller` by hand.

## Usage

```tsx
import { GenericForm, TextField } from "@/components/edust-kit/generic-form"
import { z } from "zod"

const schema = z.object({
  name: z.string().min(1, "Name is required"),
  email: z.string().email("Invalid email"),
})

<GenericForm
  schema={schema}
  initialValues={{ name: "", email: "" }}
  onSubmit={(values) => console.log(values)}
>
  <TextField name="name" label="Name" required placeholder="John Doe" />
  <TextField name="email" label="Email" type="email" />
  <button type="submit">Submit</button>
</GenericForm>
```

## Imperative API

`GenericForm` forwards a ref exposing the full control surface:

| Ref property | Type                                  | Description                   |
| ------------ | ------------------------------------- | ----------------------------- |
| `getValues`  | `() => TValues`                       | Current form values.          |
| `reset`      | `(values?: Partial<TValues>) => void` | Reset the form.               |
| `setValue`   | `(name, value) => void`               | Set a single field.           |
| `formState`  | `FormState<TValues>`                  | State (errors, dirty, etc.).  |
| `control`    | `Control<TValues>`                    | RHF control for `Controller`. |
| `form`       | `UseFormReturn<TValues>`              | The full `useForm` return.    |

```tsx
const formRef = useRef<GenericFormRef<FormValues>>(null)

<GenericForm ref={formRef} ...>...</GenericForm>

formRef.current?.getValues()
formRef.current?.setValue("email", "a@b.com")
formRef.current?.reset()
```

## TextField

`TextField` is a single-line input bound to a schema field via react-hook-form
`Controller`. It renders a label, required marker, the `Input`, and the
resolved error message.

For `type="number"`, values are coerced to a number (or `null` when empty)
before being written to the form, so `onChange` payloads stay in sync with
zod+API shapes. Use `onValueChange` for custom coercion.

| Prop            | Type                                                            | Default  | Description                                         |
| --------------- | --------------------------------------------------------------- | -------- | --------------------------------------------------- |
| `name`          | `Path<TValues>`                                                 | —        | Field name (must exist in the schema).              |
| `label`         | `string`                                                        | —        | Label text; hidden when empty.                      |
| `type`          | `"text" \| "email" \| "number" \| "password" \| "tel" \| "url"` | `"text"` | Input type.                                         |
| `placeholder`   | `string`                                                        | —        | Input placeholder.                                  |
| `required`      | `boolean`                                                       | `false`  | Renders the red `*` marker.                         |
| `disabled`      | `boolean`                                                       | `false`  | Disables the input.                                 |
| `className`     | `string`                                                        | —        | Classes for the field wrapper.                      |
| `inputClass`    | `string`                                                        | —        | Classes for the input.                              |
| `min` / `max`   | `number \| string`                                              | —        | Min/max bounds (numbers).                           |
| `step`          | `number \| string`                                              | —        | Step for number inputs.                             |
| `autoComplete`  | `string`                                                        | —        | Browser autofill hint.                              |
| `onValueChange` | `(value: string \| number \| null) => void`                     | —        | Custom value transform; bypasses built-in coercion. |

## Validation

Validation is driven entirely by the Zod schema. A field that fails its schema
rule is marked invalid (`data-invalid`) and shows the error message from the
schema:

```tsx
const schema = z.object({
  email: z.string().email("Enter a valid email address"),
})
```

## Error handling

`TextField` renders `FieldError` automatically when the field is invalid. When
an arbitrary `FieldError` is needed outside a text field, the underlying
component reads `useFormContext().formState.errors` directly.

## AsyncMultiSelectField

A searchable multi-select for remotely fetched data. Built on `Popover` and
`Command` (cmdk), it fetches options from an API with debounced search, renders
selected values as removable badges, and supports loading, error, and empty
states.

```tsx
import { AsyncMultiSelectField } from "@/components/edust-kit/generic-form"

;<AsyncMultiSelectField
  value={selectedIds}
  onChange={setSelectedIds}
  useDataHook={useLabelsHook}
  getItemDisplayValue={(item) => item.name}
  placeholder="Select labels..."
/>
```

### Props

`AsyncMultiSelectField` is generic over `<T, TParams>` where `T` is the item
type and `TParams` is the params type passed to `useDataHook`.

| Prop                  | Type                                                | Default            | Description                                                                                |
| --------------------- | --------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------ |
| `value`               | `string[]`                                          | `[]`               | Currently selected item IDs.                                                               |
| `onChange`            | `(values: string[]) => void`                        | —                  | Called with the full array whenever the selection changes.                                 |
| `placeholder`         | `string`                                            | `"Select..."`      | Text shown when nothing is selected.                                                       |
| `className`           | `string`                                            | —                  | Classes for the trigger button.                                                            |
| `badgeClassName`      | `string`                                            | —                  | Classes for the selected-value badges.                                                     |
| `debounceDelay`       | `number`                                            | `500`              | Debounce delay in ms for search input.                                                     |
| `searchPlaceholder`   | `string`                                            | `"Search..."`      | Placeholder for the search input.                                                          |
| `searchParamKey`      | `keyof TParams`                                     | `"search_by_name"` | The param key used for the search term.                                                    |
| `useDataHook`         | `(params: TParams) => { data?, isFetching, error }` | —                  | Hook that fetches items given params.                                                      |
| `selectedItemsData`   | `{ data?: { items?: T[] } }`                        | —                  | Pre-fetched data used to resolve badge labels for selected items outside the fetched page. |
| `getItemDisplayValue` | `(item: T) => string`                               | —                  | Returns the plain-text label (badges and dropdown fallback).                               |
| `renderItemLabel`     | `(item: T) => React.ReactNode`                      | —                  | Custom render for dropdown option content.                                                 |
| `getItemKey`          | `(item: T) => string`                               | `item.id`          | Unique React key for an item.                                                              |
| `getItemValue`        | `(item: T) => string`                               | `item.id`          | The value (ID) of an item.                                                                 |
| `additionalParams`    | `Partial<Omit<TParams, keyof BaseSelectParams>>`    | `{}`               | Extra params merged into every request.                                                    |
| `disabled`            | `boolean`                                           | `false`            | Disables the field.                                                                        |
| `maxSelected`         | `number`                                            | —                  | Maximum number of selections allowed.                                                      |
| `maxBadges`           | `number`                                            | `4`                | How many selected badges to render before showing `+N`.                                    |
| `showSearchIcon`      | `boolean`                                           | `false`            | Show a search icon inside the search input.                                                |
| `lazy`                | `boolean`                                           | `false`            | Fetch the dropdown list only after the popover is opened.                                  |
| `emptyIndicator`      | `React.ReactNode`                                   | —                  | Custom empty-state message.                                                                |

### With react-hook-form

```tsx
import { AsyncMultiSelectField } from "@/components/edust-kit/generic-form"
import { Controller, useForm } from "react-hook-form"

type FormValues = {
  labelIds: string[]
}

export function TaskForm() {
  const form = useForm<FormValues>({ defaultValues: { labelIds: [] } })

  return (
    <Controller
      name="labelIds"
      control={form.control}
      render={({ field }) => (
        <AsyncMultiSelectField
          value={field.value}
          onChange={field.onChange}
          useDataHook={useLabelsHook}
          getItemDisplayValue={(item) => item.name}
          placeholder="Select labels..."
        />
      )}
    />
  )
}
```

### Limiting selections

Pass `maxSelected` to cap the number of items the user can pick. When the cap is
reached the dropdown shows a hint and further selections are ignored.

```tsx
<AsyncMultiSelectField
  maxSelected={3}
  value={selectedIds}
  onChange={setSelectedIds}
  useDataHook={useLabelsHook}
  getItemDisplayValue={(item) => item.name}
/>
```

### Resolving badge labels

The trigger resolves badge labels from the fetched list plus
`selectedItemsData`. When a selected value does not appear in the current page
(e.g. paginated results), pass pre-fetched data so its badge still renders:

```tsx
const { data: selectedLabelsData } = useGetLabels(
  selectedIds.length ? { ids: selectedIds } : undefined,
)

<AsyncMultiSelectField
  value={selectedIds}
  onChange={setSelectedIds}
  useDataHook={useLabelsHook}
  selectedItemsData={selectedLabelsData}
  getItemDisplayValue={(item) => item.name}
/>
```

## AsyncSelectField

An async single-select field for remotely fetched data. Built on `Popover` and
`Command` (cmdk), fetches options from an API with debounced search, loading/
error states, and support for pre-fetching the selected item's display value.

```tsx
import { AsyncSelectField } from "@/components/edust-kit/generic-form"

;<AsyncSelectField
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.name}
  placeholder="Select an item..."
/>
```

### Props

`AsyncSelectField` is generic over `<T, TParams>` where `T` is the item type
and `TParams` is the params type passed to `useDataHook`.

| Prop                  | Type                                                | Default            | Description                                                                             |
| --------------------- | --------------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------- |
| `value`               | `string`                                            | —                  | Currently selected item ID.                                                             |
| `onChange`            | `(id: string) => void`                              | —                  | Called when the user selects an item.                                                   |
| `placeholder`         | `string`                                            | `"Select..."`      | Text shown when no item is selected.                                                    |
| `className`           | `string`                                            | —                  | Additional CSS classes for the trigger button.                                          |
| `debounceDelay`       | `number`                                            | `500`              | Debounce delay in ms for search input.                                                  |
| `searchPlaceholder`   | `string`                                            | `"Search..."`      | Placeholder for the search input.                                                       |
| `searchParamKey`      | `keyof TParams`                                     | `"search_by_name"` | The param key used for the search term.                                                 |
| `useDataHook`         | `(params: TParams) => { data?, isFetching, error }` | —                  | Hook that fetches items given params.                                                   |
| `selectedItemData`    | `{ data?: { items?: T[] } }`                        | —                  | Pre-fetched data for the selected item (used when the item is not in the current page). |
| `getItemDisplayValue` | `(item: T) => string`                               | —                  | Returns the plain-text display label (used in trigger and as fallback).                 |
| `renderItemLabel`     | `(item: T) => React.ReactNode`                      | —                  | Custom render for dropdown option content. Overrides `getItemDisplayValue` in the list. |
| `getItemKey`          | `(item: T) => string`                               | `item.id`          | Returns a unique key for React rendering.                                               |
| `getItemValue`        | `(item: T) => string`                               | `item.id`          | Returns the value (ID) of an item.                                                      |
| `additionalParams`    | `Partial<Omit<TParams, keyof BaseSelectParams>>`    | `{}`               | Extra params merged into every request.                                                 |
| `disabled`            | `boolean`                                           | `false`            | Disables the select field.                                                              |
| `showSearchIcon`      | `boolean`                                           | `false`            | Show a search icon inside the search input.                                             |
| `lazy`                | `boolean`                                           | `false`            | Fetch the dropdown list only after the popover is opened instead of on mount.           |

### With react-hook-form

```tsx
import { AsyncSelectField } from "@/components/edust-kit/generic-form"
import { Controller, useForm } from "react-hook-form"

type FormValues = {
  currencyId: string
}

export function CurrencyForm() {
  const form = useForm<FormValues>()

  return (
    <Controller
      name="currencyId"
      control={form.control}
      render={({ field }) => (
        <AsyncSelectField
          value={field.value}
          onChange={field.onChange}
          useDataHook={useCurrenciesHook}
          getItemDisplayValue={(item) => `${item.code} — ${item.name}`}
          placeholder="Select currency..."
        />
      )}
    />
  )
}
```

### Pre-fetching selected item

When the selected item may not be in the initial fetch (e.g. paginated results),
pass `selectedItemData` so the trigger button can display the correct label:

```tsx
const { data: selectedItemData } = useGetItem(selectedId ? { ids: [selectedId] } : undefined)

<AsyncSelectField
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  selectedItemData={selectedItemData}
  getItemDisplayValue={(item) => item.name}
/>
```

### Custom option labels

Use `renderItemLabel` to render arbitrary JSX in the dropdown (icons, multi-line,
badges, etc.). The trigger always uses `getItemDisplayValue` for plain text.

```tsx
<AsyncSelectField
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.code}
  renderItemLabel={(item) => (
    <div className="flex items-center gap-2">
      <span className="font-medium">{item.symbol}</span>
      <span>{item.code}</span>
      <span className="text-muted-foreground text-xs">{item.name}</span>
    </div>
  )}
/>
```

### Lazy loading

By default the dropdown list is fetched as soon as the component mounts. On
forms with many async selects (e.g. supplier, currency, product pickers on the
same page) this fires a burst of requests at once and can exceed API rate
limits. Pass `lazy` to defer fetching until the user opens the popover:

```tsx
<AsyncSelectField
  lazy
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.name}
/>
```

The selected item's label still renders immediately from `selectedItemData`
(no extra fetch is needed for the trigger while the popover is closed).

### Custom styling

Pass `className` to customize the trigger button (height, width, font size,
etc.):

```tsx
<AsyncSelectField
  className="h-7 max-w-xs text-[0.8rem]"
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.name}
/>
```

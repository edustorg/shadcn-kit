A generic async select field for single-value selection from remotely fetched data. Ideal for dropdowns backed by API endpoints with search support.

## Usage

```tsx
import { AsyncSelectField } from "@/components/edust-kit/async-select-field"

<AsyncSelectField
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.name}
  placeholder="Select an item..."
/>
```

## Props

`AsyncSelectField` is generic over `<T, TParams>` where `T` is the item type and `TParams` is the params type passed to `useDataHook`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Currently selected item ID. |
| `onChange` | `(id: string) => void` | — | Called when the user selects an item. |
| `placeholder` | `string` | `"Select..."` | Text shown when no item is selected. |
| `className` | `string` | — | Additional CSS classes for the trigger button. |
| `debounceDelay` | `number` | `500` | Debounce delay in ms for search input. |
| `searchPlaceholder` | `string` | `"Search..."` | Placeholder for the search input. |
| `searchParamKey` | `keyof TParams` | `"search_by_name"` | The param key used for the search term. |
| `useDataHook` | `(params: TParams) => { data?, isFetching, error }` | — | Hook that fetches items given params. |
| `selectedItemData` | `{ data?: { items?: T[] } }` | — | Pre-fetched data for the selected item (used when the item is not in the current page). |
| `getItemDisplayValue` | `(item: T) => string` | — | Returns the plain-text display label (used in trigger and as fallback). |
| `renderItemLabel` | `(item: T) => React.ReactNode` | — | Custom render for dropdown option content. Overrides `getItemDisplayValue` in the list. |
| `getItemKey` | `(item: T) => string` | `item.id` | Returns a unique key for React rendering. |
| `getItemValue` | `(item: T) => string` | `item.id` | Returns the value (ID) of an item. |
| `additionalParams` | `Partial<Omit<TParams, keyof BaseSelectParams>>` | `{}` | Extra params merged into every request. |
| `disabled` | `boolean` | `false` | Disables the select field. |
| `showSearchIcon` | `boolean` | `false` | Show a search icon inside the search input. |
| `lazy` | `boolean` | `false` | Fetch the dropdown list only after the popover is opened instead of on mount. |

## With react-hook-form

```tsx
import { Controller, useForm } from "react-hook-form"
import { AsyncSelectField } from "@/components/edust-kit/async-select-field"

type FormValues = {
  currencyId: string
}

export function CurrencyForm() {
  const form = useForm<FormValues>()

  return (
    <Controller
      name="currencyId"
      control={form.control}
      render={({ field }) => (
        <AsyncSelectField
          value={field.value}
          onChange={field.onChange}
          useDataHook={useCurrenciesHook}
          getItemDisplayValue={(item) => `${item.code} — ${item.name}`}
          placeholder="Select currency..."
        />
      )}
    />
  )
}
```

## Pre-fetching selected item

When the selected item may not be in the initial fetch (e.g. paginated results), pass `selectedItemData` so the trigger button can display the correct label:

```tsx
const { data: selectedItemData } = useGetItem(selectedId ? { ids: [selectedId] } : undefined)

<AsyncSelectField
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  selectedItemData={selectedItemData}
  getItemDisplayValue={(item) => item.name}
/>
```

## Custom option labels

Use `renderItemLabel` to render arbitrary JSX in the dropdown (icons, multi-line, badges, etc.). The trigger always uses `getItemDisplayValue` for plain text.

```tsx
<AsyncSelectField
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.code}
  renderItemLabel={(item) => (
    <div className="flex items-center gap-2">
      <span className="font-medium">{item.symbol}</span>
      <span>{item.code}</span>
      <span className="text-muted-foreground text-xs">{item.name}</span>
    </div>
  )}
/>
```

## Lazy loading

By default the dropdown list is fetched as soon as the component mounts. On
forms with many async selects (e.g. supplier, currency, product pickers on the
same page) this fires a burst of requests at once and can exceed API rate
limits. Pass `lazy` to defer fetching until the user opens the popover:

```tsx
<AsyncSelectField
  lazy
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.name}
/>
```

The selected item's label still renders immediately from `selectedItemData`
(no extra fetch is needed for the trigger while the popover is closed).

## Custom styling

Pass `className` to customize the trigger button (height, width, font size, etc.):

```tsx
<AsyncSelectField
  className="h-7 text-[0.8rem] max-w-xs"
  value={selectedId}
  onChange={setSelectedId}
  useDataHook={useItemsHook}
  getItemDisplayValue={(item) => item.name}
/>
```

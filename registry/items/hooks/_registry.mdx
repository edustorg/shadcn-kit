Shared hooks used across `edust-kit` registry items. Install this item (or add
it as a `registryDependency` of another item) to get a single copy of each hook
at `@/components/edust-kit/hooks/`.

## useDebouncedCallback

Returns a memoized function that debounces calls to `callback` by `delay` ms.
Any pending timeout is cleared on unmount.

```tsx
import { useDebouncedCallback } from "@/components/edust-kit/hooks/use-debounced-callback"

import * as React from "react"

const [debouncedSearch, setDebouncedSearch] = React.useState("")
const debouncedSetSearch = useDebouncedCallback(setDebouncedSearch, 500)
```

This is the same hook bundled (and previously duplicated) by
`async-select-field` and `generic-form`. Once installed through this item, both
components depend on it instead of shipping their own copy.

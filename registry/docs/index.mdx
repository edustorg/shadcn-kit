# Getting Started

**edust-kit** is a [shadcn-compatible registry](https://ui.shadcn.com/docs/registry) of
production-ready UI components built for the edust platform. Components are based on the
[shadcn](https://ui.shadcn.com) core library and Base UI, and are copied into your project so
you own and customize them.

## Requirements

Before you install anything, make sure your project is ready:

- A project initialized with the shadcn CLI — `npx shadcn@latest init`
- Tailwind CSS v4
- React 18 or newer
- Node.js 20.18 or newer

If you have not run `shadcn init` yet, do that first. It creates your `components.json` and
wires up Tailwind and your import aliases, which the installer relies on.

## Install a component

Once initialized, install any edust-kit component by name:

```bash
npx shadcn@latest add @edust-kit/button
```

The `@edust-kit` namespace is added to your `components.json` automatically the first time
you install from it. To skip the namespace and install straight from the repository instead:

```bash
npx shadcn@latest add edustorg/shadcn-kit/button
```

## What happens on install

The CLI:

1. Installs the component into your project's `ui` directory under an `edust-kit/`
   subfolder — for example `src/components/ui/edust-kit/button.tsx`. Existing components are
   never overwritten.
2. Installs any runtime dependencies (such as `@base-ui/react`).
3. Pulls the `utils` helper if it is missing.
4. Adds any custom CSS variables to your theme (`globals.css`).

## Usage

```tsx
import { Button } from "@/components/ui/edust-kit/button";
import { Badge } from "@/components/ui/edust-kit/badge";

export function App() {
  return (
    <div className="flex gap-2">
      <Button>Default</Button>
      <Button variant="destructive">Delete</Button>
      <Badge variant="success">Active</Badge>
    </div>
  );
}
```

# Getting Started

This registry is distributed as a public GitHub repository. It contains UI components built
from the [shadcn](https://ui.shadcn.com) core library and extended with custom variants.

## Requirements

- A project initialized with [shadcn](https://ui.shadcn.com) (`npx shadcn@latest init`)
- Tailwind CSS v4
- React 18+

## Install

```bash
npx shadcn@latest add edustorg/shadcn-kit/button
```

## Usage

```tsx
import { Button } from "@/components/ui/shadcn-kit/button";
import { Badge } from "@/components/ui/shadcn-kit/badge";

export function App() {
  return (
    <div className="flex gap-2">
      <Button>Default</Button>
      <Button variant="destructive">Delete</Button>
      <Badge variant="success">Active</Badge>
    </div>
  );
}
```

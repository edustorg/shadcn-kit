# Installation

There are two ways to install edust-kit components. Both do the same thing — the namespace
just gives you a shorter command.

## Prerequisites

Your project must already be initialized with shadcn:

```bash
npx shadcn@latest init
```

## Option 1: Add the namespace (recommended)

The namespace gives you short install commands like `@edust-kit/button`. Add it with the CLI:

```bash
npx shadcn@latest registry add @edust-kit=https://raw.githubusercontent.com/edustorg/shadcn-kit/main/r/{name}.json
```

Or add it manually under the `registries` field in your `components.json`:

```json
{
  "registries": {
    "@edust-kit": "https://raw.githubusercontent.com/edustorg/shadcn-kit/main/r/{name}.json"
  }
}
```

Then install by name:

```bash
# npm
npx shadcn@latest add @edust-kit/button

# pnpm
pnpm dlx shadcn@latest add @edust-kit/button

# yarn
yarn dlx shadcn@latest add @edust-kit/button

# bun
bunx --bun shadcn@latest add @edust-kit/button
```

## Option 2: Install from the repository directly

No configuration needed. The CLI reads the registry catalog from GitHub:

```bash
npx shadcn@latest add edustorg/shadcn-kit/button
```

## What the CLI does

When you install a component, the CLI:

1. Installs it under an `edust-kit/` folder inside your configured `ui` directory, so it
   never collides with your existing components:

   ```txt
   src/components/ui/edust-kit/
     button.tsx
     badge.tsx
   ```

   Your `ui` alias comes from `components.json`, so this works with standard aliases
   (`@/components/ui`), custom aliases, and workspace packages.

2. Installs the component's runtime dependencies.
3. Creates `lib/utils.ts` (with the `cn` helper) if it does not exist.
4. Merges any custom CSS variables into your `globals.css`.

## Verify the registry works

List everything available in the catalog:

```bash
npx shadcn@latest list edustorg/shadcn-kit
```

## Uninstall

Because components are copied into your project, removing one is just deleting the file and
dropping its entry from your theme:

```bash
rm src/components/ui/edust-kit/badge.tsx
```

The `@edust-kit` registry entry in `components.json` can stay — it does not affect your
bundle.
